# Plugin maintenance

This repository packages a reusable Codex native research workflow. It is not an
initialized scientific project. Modify only package-owned files; do not initialize
research/ here or edit other repositories/global Codex settings while maintaining it.

Keep native orchestration: no Python harness, agent server, MCP orchestration layer
or repeated codex exec controller. Keep the portable and compatibility manifests
consistent. Templates must contain no personal paths, secrets or actual project
results. Configuration must preserve counters, user changes and locked protocols.
Document runtime uncertainty; no default Agent may impersonate a requested role.
Do not claim role/model/permission smoke passes without independently verifiable
native metadata. Packaging checks alone cannot make a project READY_FOR_RESEARCH.
Only publish when the user has specified the destination and authorized publication.
